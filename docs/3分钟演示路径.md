## 1. 00:00 - 00:40 用户登录与首页

讲解词（可直接说）：

“这是校园跑腿系统移动端，支持手机号验证码登录和微信扫码登录。登录后进入用户首页，可以选择帮取、帮买、万能跑腿三种服务。”

操作步骤：

1. 打开 `U01` 登录页，演示“获取验证码”与“登录/注册”。
2. 登录后进入 `U02` 首页，展示三类服务入口与科技风 UI。

## 2. 00:40 - 01:40 下单到支付（核心链路）

讲解词：

“我现在从下单页发起订单，进入确认页后进入收银台。当前版本支付采用微信最小方案，前端可模拟成功/失败，后端支持支付回调与签名校验。”

操作步骤：

1. 进入任一服务页面（如 `U03`），填写表单并下一步。
2. 在 `U06` 确认金额，进入 `U07` 收银台。
3. 点击支付，展示结果页（`U08` 成功或 `U09` 失败）。
4. 强调失败可重试，成功可回订单详情闭环。

## 3. 01:40 - 02:25 订单状态与消息页

讲解词：

“订单页支持按状态查看，覆盖待支付、进行中、已完成。消息页和我的页面都已接入统一状态组件，保证移动端体验一致。”

操作步骤：

1. 进入 `U10` 订单列表，切换 Tab 查看不同状态。
2. 打开 `U11/U12/U13` 任一详情页，展示状态动作差异。
3. 快速展示 `U14` 消息页与 `U15` 我的页。

## 4. 02:25 - 02:50 跑腿员端履约闭环

讲解词：

“系统支持双端：用户端下单后，跑腿员端可在大厅接单并确认送达，订单状态会同步回用户端。”

操作步骤：

1. 在“我的”页进入跑腿员端。
2. 展示 `R02` 大厅 -> `R03` 接单 -> `R04` 配送 -> `R05` 完成。
3. 回到用户端订单页，确认状态一致。
