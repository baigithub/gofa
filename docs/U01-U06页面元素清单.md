# 校园跑腿用户端 U01-U06 页面元素清单（可直接照着画）

用途：用于今天冲刺阶段快速搭建 `U01-U06` 页面。  
说明：每页包含「页面元素」「默认文案」「交互动作」「完成验收」。

---

## U01_登录

### 页面元素
- 顶部品牌区：Logo 占位 + 标题“校园跑腿”
- 输入框 1：手机号
- 按钮 1：获取验证码
- 输入框 2：验证码
- 主按钮：登录/注册
- 底部文本：用户协议与隐私说明

### 默认文案
- 手机号占位：请输入手机号
- 验证码占位：请输入 6 位验证码
- 说明：未注册手机号将自动创建账号
- 协议：登录即表示同意《用户协议》《隐私政策》

### 交互动作
- 点击“获取验证码” -> 提示“验证码已发送”
- 输入合法手机号 + 验证码后，主按钮可点击
- 点击“登录/注册” -> 跳转 `U02_首页`

### 完成验收
- [ ] 输入框与按钮齐全
- [ ] 按钮禁用/可用状态明确
- [ ] 可跳转到首页

---

## U02_首页

### 页面元素
- 顶部：校区选择、搜索框
- 服务入口卡片（3 个）：
  - 帮取快递
  - 帮买商品
  - 万能跑腿
- 公告栏：滚动/静态一条
- 推荐区（可占位）：高频服务快捷入口
- 底部导航：首页 / 订单 / 消息 / 我的

### 默认文案
- 搜索占位：搜索服务或问题
- 公告：高峰期配送时效可能延长，请提前下单

### 交互动作
- 点击“帮取快递” -> `U03`
- 点击“帮买商品” -> `U04`
- 点击“万能跑腿” -> `U05`
- 点击底部“订单” -> `U10`（后续页面）
- 点击底部“消息” -> `U14`（后续页面）
- 点击底部“我的” -> `U15`（后续页面）

### 完成验收
- [ ] 3 个服务入口可见
- [ ] 底部导航完整
- [ ] 可跳转到 U03/U04/U05

## U03_帮取快递_填写

### 页面元素
- 顶部标题：帮取快递
- 表单字段：
  - 取件地址
  - 送达地址
  - 快递公司
  - 取件码
  - 期望送达时间（尽快送达/指定时间）
  - 联系电话
  - 备注（可选）
- 底部主按钮：下一步（确认订单）

### 默认文案
- 取件地址占位：请选择快递站点
- 送达地址占位：请选择宿舍/教学楼
- 取件码占位：请输入取件码

### 交互动作
- 必填项校验通过后，点击“下一步” -> `U06`
- 缺少必填项时提示：
  - 请填写取件码
  - 请填写送达地址

### 完成验收
- [ ] 必填项标识完整
- [ ] 至少 2 条错误提示可演示
- [ ] 可跳转到 U06

## U06_确认订单

### 页面元素
- 顶部标题：确认订单
- 信息模块 1：地址信息卡片（起点、终点、联系人）
- 信息模块 2：订单说明（服务类型、备注）
- 费用明细：
  - 跑腿费
  - 商品预估（帮买显示）
  - 加价费（可选）
  - 实付金额（高亮）
- 优惠模块：暂无可用优惠券（占位）
- 底部主按钮：提交并支付

### 默认文案
- 跑腿费：¥8.00
- 商品预估：¥20.00
- 加价费：¥2.00
- 实付金额：¥30.00
- 底部提示：提交即表示同意《跑腿服务协议》

### 交互动作
- 点击“提交并支付” -> `U07_收银台_微信支付`
- 点击地址区可返回对应填写页编辑（可选）

### 完成验收
- [ ] 金额明细分层清晰
- [ ] 实付金额高亮
- [ ] 可跳转到 U07

## 绘制顺序（建议）

1. 先画 `U06`（作为后续服务页复用模板）
2. 再画 `U03/U04/U05`（仅替换字段差异）
3. 最后画 `U01/U02`（结构简单，收尾快）

按以上顺序通常可在 60-90 分钟内完成 U01-U06 第一版。
